# Notes App (Flutter + Appwrite)

A notes application built with Flutter and Appwrite, following the Teknolabs
Cross-Platform Mobile Dev course.

## Features
- Register, login, and logout (Appwrite Auth)
- Create, read, edit, and delete notes (Appwrite TablesDB)
- Each user sees only their own notes

## Run it
1. Install Flutter and run `flutter pub get`
2. Copy `.env.example` to `.env` and fill in your Appwrite values
3. Run `flutter run -d chrome`
